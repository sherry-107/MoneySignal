## 📌 프로젝트 소개

예·적금 금리 비교를 위해 은행 앱을 하나씩 열어봐야 했던 경험, 환율이나 주변 은행 정보가 여러 앱에 흩어져 있어 불편했던 경험이 있으셨나요?

**MoneySignal**은 금융을 처음 접하는 사회초년생과 금융 초보자를 위해, 흩어진 금융 정보를 한 곳에서 쉽게 확인할 수 있도록 설계된 올인원 금융 정보 플랫폼입니다.

## ✨ 주요 기능

### 💱 실시간 환율
- 27개국 환율 실시간 조회
- 기간별 환율 추이 차트
- 통화 간 환율 계산기

### 🏦 금융 상품 비교
- 금감원 API 기반 300+ 예·적금 상품 목록
- 사용자 맞춤 상품 추천 (RAG 기반)
- 상품별 예상 수익 계산기
- 여러 상품 동시 비교 및 차트 시각화
- 은행·금리·기간 조건 필터 검색

### 📍 주변 은행 검색
- 현재 위치 기반 주변 은행 지도 표시
- 즐겨찾기 관리
- 카카오맵 길찾기 연결 (도보·차량 실시간 경로)

### 🤖 AI 챗봇 — 한돈이🐷
- ChromaDB 임베딩 기반 금융 상품 추천
- GPT-4.1-mini 연동 자연어 응답
- 서비스 Q&A 및 무관 질문 자동 거부

### 📈 금/은 시세
- 기간 지정 금·은 가격 차트
- 관련 네이버 뉴스 기사 조회

### 🎬 유튜브 영상
- 관심사별 금융 유튜브 영상 제공 (5페이지)
- 정렬 및 영상 세부 정보 조회

### 💬 커뮤니티
- 카테고리별 금융 정보 게시판
- 게시글 작성·조회·수정·삭제
- 댓글 · 좋아요 기능

### 👤 회원 관리
- 일반 회원가입 / 카카오 소셜 로그인
- JWT 기반 인증
- 마이페이지 (프로필·관심상품 관리)
- 금융 정보 입력 (투자성향·목표·나이 등)

## 🎯 기대 효과

| 효과 | 내용 |
|:---:|:---|
| **금융 접근성 향상** | 금융 초보자도 AI 챗봇으로 쉽게 맞춤 상품 추천 및 질의응답 가능 |
| **정보 탐색 시간 절감** | 흩어진 금융 정보를 한 곳에서 빠르게 비교·확인 |
| **원스톱 금융 서비스** | 환율·상품·은행 길찾기까지 하나의 플랫폼에서 처리 |
| **데이터 기반 개인화** | 관심 상품·즐겨찾기 데이터로 점점 더 정확한 추천 제공 |
| **신뢰성 있는 정보** | 공공 금융 API 기반 데이터로 정확하고 최신 정보 유지 |
